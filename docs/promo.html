Android and iPhone

What works where

Android lets an app see what's on screen in other apps, which is how Shorts Tracker counts videos. iPhone doesn't allow that, so an iPhone version could only measure time.

Install it

The download folder also has a step-by-step text guide, with fixes for Xiaomi, Samsung, OnePlus and other phones.

  1. Download the APK

    Open the Drive folder on your phone and tap ShortsTracker-0.1.apk.

  2. Allow the install

    Android asks before installing apps from outside the Play Store. Tap Settings, allow it, then Install.

  3. Turn on tracking

    Open the app, tap Accessibility, find Shorts Tracker and switch it on. If the switch is greyed out, go to App info, tap ⋮ and choose "Allow restricted settings".

  4. Keep scrolling

    Watch Shorts or Reels as usual. Set the app's battery usage to Unrestricted so your phone doesn't close it.
